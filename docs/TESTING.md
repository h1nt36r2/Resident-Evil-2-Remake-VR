# Проверки 0.7.1-scene

Пройдены полный локальный набор Lua-сценариев и 32 проверки экспортированных native-сигнатур. Новый тест меняет объект игрока при неизменных указателях оборудования: счётчик сессии растёт один раз, старые ledger/fault/pump очищаются. Проверены полный сброс движка взаимодействий, автоматический выбор титульного фона без сохранённой настройки, отказ при неоднозначных названиях и исключение gameplay HUD. Реальный PowerShell-установщик проходит миграцию, обновление с 0.5.5/0.6.0 и откат в изолированных папках. Сборка C# проходит встроенные self-test.

Проверка новой игры в Quest/SteamVR и устранение исчезновения тела/сцены в правом глазу не выполнены. Автоматический обход меню зависит от имён реальных GUI-слоёв; неизвестные имена автоматически попадают в отчёт. Ни один тест не подтверждает изменение графических настроек при новой игре.

# Проверки 0.7.0-weapons

На Windows прошли Lua-проверки взаимодействий и native-границы с имитацией SDK: удержание, чека, одно создание и списание, отсутствие повторов и бросков после standby; запрет native атаки в физическом режиме; перенос скорости; исключение игрового HUD из коррекции титульного меню. Отдельно проверены конечные патроны обычного оружия и отсутствие запрета бонусного.

Публикуемые сценарии можно запустить через `python tests/run_lua.py` с переменной `LUA_DLL`, указывающей на установленную библиотеку Lua 5.3. Скрипт проверяет синтаксис всего runtime. Никаких операций с игрой он не выполняет.

Сборка C# и self-test помощника прошли. Реальный PowerShell-установщик проверен в изолированных папках: новый пакет, миграция, обновление, откат, сохранение пользовательских настроек. Официальный скрипт гранат заменяется только при совпадении известного хеша.

**Не проверено:** Quest/SteamVR в реальной RE2, реальные сигнатуры и семантика grenade generator на RT/NonRT, обе гранаты, последний предмет в стопке, анимация чеки, контратаки, сюжетные миниган/ракетница, исправление маленького городского фона. Готовность адаптера определяется при запуске и попадает в диагностику. Предыдущий статус сохранён ниже как история.

# Статус проверок

Этот публичный исходный снимок восстановлен из ранее собранного установочного архива 0.6.0. Оригинальная Windows-папка разработки в момент подготовки репозитория недоступна.

В предыдущем Windows workspace проходили:

- исполнение настоящих Lua-модулей с подменой границ SDK / VR, включая сохранение количества патронов, магазин, револьвер, помпу, standby и порядок выбора гранаты;
- сопоставление 32 SDK-сигнатур с экспортированными метаданными RE2;
- реальный установщик PowerShell в изолированных папках: установка, обновление, миграция probe, откат и удаление; список процессов подменялся;
- компиляция C# x64, self-test структуры INPUT / проверки окна, генерация текстур и проверка матриц пояса;
- проверки запуска PowerShell и целостности установочного ZIP.

Оригинальные исследовательские фикстуры и тестовые скрипты не входили в установочный архив и потому не представлены здесь как будто восстановленные. CI этого репозитория не выдаёт их за запущенные тесты. Сохранены встроенные C# self-tests, доступные из восстановленных исходников.

**Не подтверждены:** полный Quest-тест пояса, положение в обоих глазах, работа каждого оружия, совпадение зон захвата, возвращение SteamVR после standby, устранение Fatal D3D 22 / 25 и прохождение всей кампании.

В новой среде выполнена только проверка восстановления исходников / упаковки, целостности архива и документации. Публикация на GitHub не повышает этот уровень готовности.

Для нового PR записывайте отдельно: тест чистой логики; тест SDK-границы; настоящие результаты в игре; runtime / Steam-ветку / драйвер / подключение шлема. Регрессия должна иметь минимальный сценарий, а неопределённый результат — явную пометку.
