# RE2 Immersive VR 0.6.0 — экспериментальная сборка

Готовый пакет для Windows, Resident Evil 2 Remake (Steam) и Quest 3 через SteamVR / OpenVR.

## Установка
1. Скачайте **RE2IVR-0.6.0-belt.zip** из Assets и распакуйте в отдельную папку.
2. Закройте игру и запустите **Install.cmd**. Установщик найдёт Steam-версию игры и загрузит проверенный REFramework, если он ещё не установлен. Для загрузки нужен интернет; отдельно ставить фреймворк не требуется.
3. Подключите шлем к SteamVR и запустите **Play.cmd** из распакованного пакета.
4. Для обновления используйте Install.cmd новой версии. Сохраните пакет для Rollback.cmd и Uninstall.cmd.

## Что включено
- Управление оружием с удержанием grip, быстрые слоты и пространственный пояс с иконками.
- Выбор ножа, гранат и оружия с проверкой наличия предметов в инвентаре.
- Обычная перезарядка по правой B; экспериментальная физическая перезарядка выключена по умолчанию.
- Спринт по нажатию левого стика, центрирование по нажатию правого.
- Мост ввода для диалога RE.NET: в меню Insert выберите Controller dialog input: space или enter, затем удерживайте левый grip + правую B одну секунду. Для нераспознанного меню есть Send real space after Insert closes.
- Сбор диагностики, откат и восстановление VR-настроек.

## Известные ограничения
Пояс отображает пространственные плоские иконки, а не объёмные модели предметов. Проблемы шеи/головы, различий между глазами на некоторых костюмах, возврата после снятия шлема и Fatal D3D 22/25 остаются предметом тестирования. Полное прохождение и работа всех механик на Quest не подтверждены. Сборка и встроенные проверки проходят; это не заменяет проверку в шлеме.
