# Resident Evil 2 Remake VR — 0.8.1-menu-input

Скачайте **RE2IVR-0.8.1-menu-input.zip**, закройте RE2, распакуйте архив, запустите **Install.cmd**, затем новый **Play.cmd**. Привязки включены автоматически.

## Назначение быстрого доступа

1. Откройте обычный инвентарь игры и экипируйте нужное основное оружие.
2. Удерживайте нажатым левый стик (**L3**).
3. Отклоните **правый стик** вверх, вниз, влево или вправо. Экипированное основное оружие назначается соответствующей ячейке быстрого доступа.
4. Отпустите L3 перед следующим назначением. Одна комбинация выполняет одно действие; диагональные и одновременные L3+R3 не назначают слот.

Назначается экипированное основное оружие. Перед выбором другого оружия используйте обычную команду Equip / Экипировать в инвентаре. Боеприпасы и предметы не создаются и не списываются. Используется штатный Inventory.setShortcutSlot с проверкой результата. Верхняя ячейка затем берётся правым grip с правого бока, нижняя — за правым плечом.

Y сохранена для открытия/закрытия инвентаря: эта кнопка уже занята в текущей схеме REFramework. Использован предложенный вариант с нажатием стика.

## Этажи карты

- **L3** на открытой карте — этаж ниже.
- **R3** — этаж выше.
- На удержании нет повторов. Для следующего этажа отпустите и нажмите снова.
- Вне карты эти команды не выполняются. Спринт и перецентровка вне меню сохраняются. Окна подтверждения не получают этих команд.

Карта использует native GUI-команды MoveUpD / MoveDownD, применяемые REFramework для D-pad. Здесь нет отправки клавиш Windows и зависимости от клавиатурных T/G.

## Статус

Пройдены Lua-сценарии контекста, направлений, удержания, смены меню и подтверждения назначения. Проверены 42 экспортированные сигнатуры RE2; GUI-trigger setters дополнительно проверяются на текущем билде перед вызовом. C#-помощник собирается и проходит self-test. Реальное отображение/переключение этажей в Quest ещё требует проверки.

При отказе игры или несовместимом API причина записывается в menuControls / menuControlsError отчёта Collect.cmd. Назначение автоматически не повторяется после неопределённого результата.
