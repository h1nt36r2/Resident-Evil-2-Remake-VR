# Resident Evil 2 Remake VR — 0.8.2-ada-fix

Кандидат исправления ситуации, когда EMF Ады не активирует электрощит.

Скачайте **RE2IVR-0.8.2-ada-fix.zip**, закройте RE2, распакуйте архив, запустите **Install.cmd**, затем новый **Play.cmd**. Полный перезапуск необходим для замены уже загруженного скрипта прицела.

В эпизоде Ады автоматически включается режим совместимости:
- Оружие и EMF используют штатное управление игры/REFramework; наш пояс и перехваты стрельбы/перезарядки не мешают устройству.
- Прицел устройства не переносится по пулевому raycast. Штатный маркер остаётся видимым.
- Нет автоматического взлома, изменения целей, прогресса или выдачи предметов.
- Смена персонажа учитывается даже при повторном использовании Player-объекта. Имена/классы и состояние триггера добавлены в диагностику.

Для проверки: выберите EMF, удерживайте правый grip, наведите штатный маркер на нужный узел и удерживайте правый триггер до завершения прогресса. Проверьте щит и вентилятор отдельно.

В этой сборке **физический пояс для Ады временно не используется**. Это режим совместимости ради прохождения; для Леона/Клэр физическое управление сохраняется. Полный план: https://github.com/h1nt36r2/Resident-Evil-2-Remake-VR/blob/main/docs/ADA.md

Lua и экспортированные контракты проверены. Реальная активация щитка в Quest ещё не подтверждена. Повторный расширенный локальный установочный тест заблокирован автоматической проверкой безопасности из-за внешней телеметрии; он не повторялся и не объявляется успешным. Сама установка не добавляет отправку телеметрии: новый код использует игровые методы и файлы мода, без новой сетевой логики.
