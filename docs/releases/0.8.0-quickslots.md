# Resident Evil 2 Remake VR — 0.8.0-quickslots

Скачайте **RE2IVR-0.8.0-quickslots.zip**, закройте RE2, распакуйте архив и запустите **Install.cmd**, затем новый **Play.cmd**. REFramework загрузится автоматически. Изменения включены без настроек меню мода.

## Основные зоны

| Зона правой руки + свежее нажатие grip | Предмет |
|---|---|
| Кобура на правом боку | Верхняя ячейка быстрого доступа игры |
| За правым плечом | Нижняя ячейка быстрого доступа игры |
| Подсумок гранаты на передней части пояса | Имеющаяся ручная граната |
| Соседний подсумок светошумовой | Имеющаяся светошумовая граната |

Назначения верхней и нижней ячеек читаются из реального инвентаря, без угадывания номеров enum. Назначьте оружие обычным способом в игре; менять настройки мода не требуется. Пустая ячейка ничего не выдаёт. Кобура больше не подменяет назначение текущим оружием. Плечевая зона имеет радиус около 23 см и следует за горизонтальным направлением головы.

## Исправления гранат

- В список пояса включены дополнительные оружия с IsSubWeapon, даже если IsWeapon выключен.
- Выбор выполняется штатным Inventory.equipSlot: игра сама обновляет активный слот инвентаря, а не только компонент экипировки.
- При нажатии в пустом/недоступном подсумке захват поглощается, а не превращается в захват текущего пистолета.
- Среди близких зон выбирается ближайшая, а не первая по порядку инвентаря.
- Выбранный дополнительный предмет удерживается правым grip через проверку checkHold. Левый grip при удержании гранаты не должен выбирать нож: он используется для физического извлечения чеки. Обычный левый grip вне этого действия сохраняет игровой нож.
- То же нажатие grip передаётся из выбора в удержание гранаты. Отпускать и снова хватать её не требуется. Поднесите левую руку к гранате, зажмите левый grip и отведите руку примерно на 6 см; бросок происходит при отпускании правого grip.
- Пояс обновляет инвентарь чаще; добавлен отдельный значок нижнего слота за плечом. Это по-прежнему плоские пространственные изображения, а не модели игровых оружий.

## Проверки и ограничения

Прошли Lua-сценарии зон, пустых ячеек, смены назначений, приоритета гранаты, передачи захвата и однократного броска. Проверены 35 экспортированных сигнатур RE2, включая checkHold, getSlot(Shortcut) и equipSlot(Int32). В тесте SDK выбранная граната получает удержание правой рукой, нож в этот момент не получает его, обычный нож возвращается после отпускания рук. Сборка Windows и встроенные проверки помощника проходят.

Тесты используют имитацию границы SDK. Реальное действие checkHold, чтение enum на конкретном RT/NonRT-билде и видимость гранаты в Quest ещё требуют проверки в игре. Если назначение не прочиталось, мод не берёт случайное оружие; причина попадёт в Collect.cmd (shortcutStatus / beltSelection / beltHold). Левую и правую ячейки быстрого доступа эта версия не переносит в новые физические зоны.
