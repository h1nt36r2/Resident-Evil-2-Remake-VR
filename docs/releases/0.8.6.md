# Resident Evil 2 Remake VR — 0.8.6

Полный архив со всеми предыдущими изменениями, включая извлечение дробовика из-за плеча в 0.8.5. Изменена схема дополнительного оружия по уточнённому запросу пользователя.

## Выбор и удержание — отдельные действия

- Grip любой рукой на значке ножа, обычной гранаты или флешки выбирает этот предмет из инвентаря.
- Левый grip вне значков достаёт и удерживает выбранное дополнительное оружие штатным способом RE2/REFramework. Сам предмет остаётся в правой руке.
- Отпускание левого grip прекращает удержание, но сохраняет выбранный предмет. Следующее нажатие снова достаёт его.
- Правый grip у бедра или за правым плечом по-прежнему отвечает за основное оружие. Левый grip не выбирает эти две зоны.
- Пустой подсумок ничего не выдаёт. Выбор во время удержания уже активированной гранаты заблокирован.

## Граната

Выберите значок → удерживайте левый grip → нажмите правый триггер → бросьте движением правой руки, отпустив левый grip.

Триггер должен быть отпущен перед снятием чеки. Правый grip больше не удерживает дополнительное оружие. Сохраняется один нативный снаряд и одно списание при активации; отпускание не создаёт ещё одну гранату. Запал остаётся штатным; фактическое время и взрыв в руке требуют проверки в игре.

## Исправления ножа

Убрана проверка количества гранат для ножа: владение проверяется через непустой живой слот инвентаря. Выбор дополнительного оружия больше не требует принудительной смены по контракту WeaponParts. Удалена старая блокировка левого grip, предназначенная для прежнего вытягивания чеки второй рукой.

## Установка

Закройте RE2, распакуйте RE2IVR-0.8.6.zip в новую папку, запустите Install.cmd и затем Play.cmd при работающем SteamVR. Предыдущие патчи отдельно не нужны; REFramework загружается установщиком.

## Проверки

Автотесты проверяют выбор значка обеими руками, раздельный выбор/удержание, удержание и отпускание левого grip, сохранение выбора ножа после гранаты, отсутствие проверки стека гранат для ножа, запрет смены предмета у активированной гранаты и прежний захват дробовика. Это тесты кода с двойниками SDK, не подтверждение работы на Quest.

Практическая проверка: выбрать гранату, достать/убрать левым grip без триггера, выбрать нож, достать/убрать нож дважды; повторить для флешки. После этого проверить активацию и физический бросок. Ограничения AFR/Ады из 0.8.4 сохраняются.
