# Resident Evil 2 Remake VR — 0.7.1-scene

Установочный ZIP: **RE2IVR-0.7.1-scene.zip**. Закройте RE2, распакуйте архив и запустите **Install.cmd**, затем **Play.cmd**. Включать исправления в меню мода не требуется.

## Автоматические изменения

- Временная недоступность компонента при построении сцены ставит обработку на паузу и повторяет чтение на следующем кадре; она больше не отключает весь мод до ручного включения.

- При смене объекта игрока (новая игра, загрузка другого персонажа, возврат из меню) сбрасываются старые блокировки боеприпасов, ожидания выстрела, помповый цикл и состояния перезарядки/гранаты. Состояния с ошибкой не переносятся на другого игрока. При обычной смене оружия или снятии шлема блокировки не снимаются, чтобы нельзя было обойти расход патронов.
- Пояс сбрасывает кэш и немедленно перечитывает инвентарь нового игрока. Старая отложенная команда выбора предмета отменяется.
- Фон титульного меню распознаётся автоматически по смысловому имени GUI-слоя, если кандидат ровно один. Для него применяется экранный режим без ручного выбора. Неизвестные/неоднозначные слои не меняются; отчёт автоматически попадает в Collect.cmd. Это обход с ограниченным распознаванием, а не подтверждённое исправление всех вариантов меню.
- Параметры графики игры, масштаб глаз и межзрачковое расстояние не переписываются при смене сцены. Поправка высоты повторно не накапливается.

## Правый глаз

Сброс состояния мода не является доказанным исправлением исчезновения тела в одном глазу. В REFramework есть отдельная известная проблема RT-костюмов: https://github.com/praydog/REFramework/issues/400 . Подтверждения, что новая игра меняет графические настройки, пока нет. Нельзя автоматически менять костюм или Steam-ветку игры по предположению о причине.

## Проверено

Lua-сценарии: автоматический выбор фона, отказ при неоднозначности, исключение игрового HUD; сброс сессии при смене игрока при повторно использованных указателях оборудования; отсутствие повторного сброса каждый кадр. Предыдущие сценарии оружия, гранат и расхода боеприпасов проходят. Проверки имитируют границу SDK и не заменяют испытание новой игры в Quest / SteamVR.
