# Resident Evil 2 Remake VR Mod — RE2 Immersive VR

**An open-source PCVR mod for Resident Evil 2 Remake (2019), built on REFramework, targeting Meta Quest 3 through SteamVR / OpenVR. Includes motion-controller weapon handling, spatial inventory belt, a Windows installer and experimental physical reload mechanics.**

**VR-мод для Resident Evil 2 Remake:** оружие и предметы с VR-контроллеров, пояс с кобурой и установка одним действием.

Открытый экспериментальный мод для **Resident Evil 2 Remake (2019)**: управление оружием и предметами с VR-контроллеров, пояс с кобурой и инструменты восстановления управления. Основан на [REFramework](https://github.com/praydog/REFramework).

**Текущая версия: 0.6.0-belt, ранняя тестовая сборка.** Основная конфигурация проекта — Windows, Steam-версия RE2 и Meta Quest 3 через **SteamVR / OpenVR**. Полное прохождение кампании, стабильность на разных GPU и работа пояса в шлеме пока не подтверждены. Это не официальный продукт Capcom, Meta или Valve.

**Пояс пока состоит из плоских изображений с пространственным положением**, а не объёмных игровых моделей. Закруглённые чехлы показывают реальные количества предметов; пустые слоты ничего не выдают. Карман боеприпасов в обычном режиме информационный. Передвижение, прицеливание, броски, удары и контратаки в основном выполняются самой игрой и REFramework.

## Установка

1. Установите свою лицензионную Steam-копию RE2 Remake. Поддержка конкретного билда и костюма может отличаться; для первого запуска сохраните резервную копию важных настроек.
2. Закройте RE2. Распакуйте **установочный архив** в отдельную папку. Не запускайте скрипты прямо из ZIP.
3. Запустите `Install.cmd`. Если путь не определился, укажите папку, в которой находится `re2.exe`.
4. Запустите SteamVR, подключите Quest и убедитесь, что контроллеры отслеживаются.
5. Запустите **`Play.cmd` именно из новой папки сборки**. Он запускает помощник ввода / пояса и затем RE2 через Steam.

Ручная предварительная установка REFramework не требуется. Установщик использует официальный **v1.5.9.1**: скачивает подходящий архив RT / NonRT либо использует приложенный проверенный RT-архив, если он включён в сборку. При скачивании нужна сеть. Игру, Steam, SteamVR и приложения для подключения Quest установщик не устанавливает.

**GitHub → Code → Download ZIP — архив исходников, не готовый установщик.** Готовый установочный пакет доступен по ссылке выше. Для самостоятельной сборки воспользуйтесь [инструкцией разработчика](docs/DEVELOPMENT.md). Исходники в этом репозитории не содержат игровых ресурсов, сохранений или готовых DLL.

В 0.6.0 установщик сохраняет `re2_config.ini`: не назначает высокое качество текстур, HDR или разрешение. Из настроек REFramework он включает первый вид, скрытие головного сустава и отключает принудительное повышение FPS. Уже завышенные параметры нужно разово снизить в самой игре / SteamVR. `Repair-SteamVR.cmd` — отдельное дополнительное действие, которое меняет профиль отображения; для обычного обновления оно не требуется.

## Основное управление

| Действие | Управление по умолчанию |
|---|---|
| Передвижение | Левый стик, штатное управление REFramework |
| Спринт | Нажатие левого стика, L3; режим удержания/переключения зависит от игры |
| Взять оружие | Отпустить и снова зажать правый grip; быстрый захват работает в любом месте |
| Держать оружие | Продолжать удерживать правый grip |
| Отпустить оружие | Отпустить grip; мод возвращает его в состояние кобуры |
| Перезарядить | **Правая B** в обычном режиме; нужны подходящие патроны в инвентаре |
| Взять предмет с пояса | Свободная правая рука у нужного места + свежее нажатие grip |
| Перецентровка | Удерживать R3 около секунды, не двигая стики |
| Меню мода на ПК | `Insert` → `RE2 Immersive VR` |

Пояс следует за оценкой талии по позиции и горизонтальному направлению головы. Он вынесен вперёд на 3 см; в меню доступны **Belt forward: 0 / 3 / 6 cm**. Это сдвигает визуальные слоты и зоны захвата, не скелет персонажа и не геометрию глаз. Скрыть пояс: **Hide SteamVR spatial belt**.

Если RE2 уже запущена напрямую из Steam, отдельно запустите `Start-Input-Bridge.cmd`. При отсутствии пояса нажмите **Refresh SteamVR belt status** и посмотрите отчёт `Collect.cmd`.

## Как закрыть сообщение RE.NET, не снимая шлем

Не путайте обычное сообщение об ошибке передачи статистики с **Fatal D3D error**. Фатальную ошибку рендера нельзя исправить подтверждением окна.

1. Используйте новый `Play.cmd`, чтобы помощник был запущен.
2. В меню `Insert` выберите **Controller dialog input: space**. Если конкретное меню не принимает Space, попробуйте **enter**.
3. Закройте Insert. При открытом игровом окне удерживайте **левый grip + правый B одну секунду**, затем отпустите.
4. Если мод не распознал диалог, выберите **Send real space after Insert closes** и закройте Insert в течение 10 секунд. Эта явная команда не требует распознавания типа окна игры.

Снятие шлема не требуется. **Mouse** — альтернативный режим: он нажимает в текущем положении курсора Windows и сам не наводится на OK. Если курсор не над кнопкой, клик не поможет; используйте Space/Enter или наведите курсор через SteamVR Desktop и затем закройте панель SteamVR.

Помощник отправляет ввод только в активное главное окно соответствующей RE2, не переключает фокус и отказывается нажимать системные модальные окна Windows. Статус `input_sent` означает отправку события, а не доказанное закрытие диалога. Возможны ограничения Windows при разных уровнях привилегий процессов. Подробности: [диалоги и диагностика](docs/TROUBLESHOOTING.md).

Чтобы прекратить отправку статистики, можно вручную выбрать **главное меню RE2 → Options / Настройки → RE NET → Play Data Settings / отправка игровых данных → Off / Выкл.** Мод сам эту настройку не меняет.

## Экспериментальная ручная перезарядка

В меню есть **Enable experimental physical reload**. В этом режиме кнопка B извлекает магазин / открывает оружие, а обычная кнопочная перезарядка поддерживаемого оружия блокируется.

- Магазин: взять подходящий магазин левой рукой у подсумка, физически вставить, захватить и оттянуть затвор, отпустить.
- Револьвер: открыть барабан, вставлять отдельные патроны из подсумка; закрыть кнопкой или распознаваемым движением кисти.
- Помповый дробовик: после выстрела левой рукой отвести цевьё назад примерно на 10 см и вернуть вперёд; зарядка — по одному патрону.
- Однозарядный профиль: открыть, вставить один снаряд / патрон, закрыть.

Набор действий зависит от профиля оружия. Движение настоящих костей магазина / затвора / барабана рукой пока не реализовано. Неизвестное оружие сохраняет штатное управление или требует ручного выбора профиля. **Native button reload** возвращает обычный режим. Наличие кода и автотестов не означает подтверждённую поддержку каждого оружия в кампании.

## Обновление и удаление

- Закройте игру, распакуйте новую сборку в новую папку и запустите её `Install.cmd`.
- Запускайте новый `Play.cmd`, чтобы использовалась текущая версия помощника.
- `Rollback.cmd` откатывает управляемые файлы предыдущей установки. Он не равнозначен откату всех пользовательских настроек.
- `Uninstall.cmd` удаляет управляемую установку с проверкой состояния и восстановлением резервных копий там, где они есть.
- `Restore-VR-Settings.cmd` отдельно восстанавливает последнюю сохранённую копию профиля отображения, если такой профиль применялся.
- Сохранения игры в состав пакета и репозитория не входят.

## Известные проблемы

- **Руки / тело только в одном глазу:** известный класс проблем REFramework с RT-версией и отдельными костюмами. Это не считается исправленным. Возможные обходы — другой костюм или доступная Steam-ветка `dx11_non-rt` с повторной установкой подходящего REFramework.
- **Шея перекрывает обзор:** скелет и привязка камеры ещё требуют доработки. Сдвиг пояса не является исправлением головы / шеи.
- **Fatal D3D 22 / 25:** сообщались во время испытаний. Точная причина на тестовом ПК не установлена; код ошибки и полный текст DXGI важнее одного числа. После фатального сбоя нужен перезапуск RE2.
- **Просадка после снятия / надевания шлема:** обработка потери трекинга переработана, прежние настройки рендера частично восстанавливались в 0.5.5. Реальное устранение зависания не подтверждено.
- **Hardware-accelerated GPU scheduling:** REFramework предупреждал о включённом HAGS на тестовом ПК. Отключение этой настройки в Windows с перезагрузкой — отдельный рекомендованный upstream шаг проверки низкого FPS, не гарантия исправления драйвера.
- **Нечёткая картинка:** разрешение глаз в OpenVR задаётся SteamVR, а не размером окна на мониторе. На время проверки стабильности используйте 100% для RE2 и избегайте одновременного повышения нескольких масштабов.
- Дополнительные игровые Mesh-копии отключены после сообщений о вылетах; новый пояс использует отдельный процесс и OpenVR Overlay. Его реальная нагрузка ещё не измерена.

## Сообщить о проблеме

Запустите `Collect.cmd` из папки установленной сборки. Он создаёт ZIP с диагностикой мода и выбранными параметрами отображения. **Просмотрите архив перед публикацией:** диагностические данные и пользовательские файлы не следует автоматически отправлять в публичные Issues. Не прикладывайте сохранения, полные папки игры, учётные данные или приватные пути без необходимости.

В Issue укажите версию мода, RT/NonRT, GPU и драйвер, способ подключения Quest, шаги воспроизведения и полный текст ошибки. Шаблоны находятся в `.github/ISSUE_TEMPLATE`.
