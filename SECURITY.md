# Безопасность

Не публикуйте пароли, токены, сохранения или полные диагностические архивы в публичных Issues. Для приватной уязвимости используйте GitHub **Report a vulnerability**, если этот способ включён владельцем. Если приватный канал не настроен, создайте Issue только с просьбой о приватном контакте, без подробностей эксплуатации и секретов.

Помощник ввода проверяет активное главное окно RE2 и её путь. Он не должен перехватывать клавиатуру глобальным hook, красть фокус, обходить уровни привилегий или автоматически подтверждать системные диалоги. Менять эти ограничения в обход проверки владельца не следует.

Единственной поддерживаемой стабильной версии пока нет. Исправления сначала проверяются как изменения экспериментальной ветки; сроки реакции не гарантируются.
