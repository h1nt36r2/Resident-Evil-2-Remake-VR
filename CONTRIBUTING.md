# Участие в разработке

Проект находится на ранней стадии. Перед крупной доработкой откройте Issue с конкретным сценарием и ожидаемым поведением. Для изменения кода используйте отдельную ветку и pull request; `main` предназначена для reviewable-снимков.

В PR опишите проблему, изменение, способ проверки и ограничения. Разделяйте тест чистой логики, проверку SDK-сигнатур и настоящий запуск RE2 / SteamVR. Не называйте проверку с подменой SDK доказательством работоспособности на шлеме.

- Сохраняйте обычный запуск и возможность выключить экспериментальную механику.
- Не добавляйте прямые записи в сохранения, синтетические боеприпасы или бесконечный резерв.
- Проверяйте принадлежность предмета перед выбором; при непроверенном результате не повторяйте расход автоматически.
- Не меняйте IPD и eye projection для исправления отсутствующих моделей.
- Не добавляйте игровые ресурсы, исполняемые файлы, приватные отчёты, токены и настройки конкретного пользователя в git.
- Для стороннего кода сохраняйте источник, версию, лицензию и описание локальных изменений.

Изменение пояса требует проверки положения в обоих глазах, совместимости зон захвата с изображениями, потери трекинга, перезапуска SteamVR и нагрузки на GPU. До таких испытаний отмечайте статус как experimental.

Обычные коммиты:

```bash
git checkout -b fix/short-description
git add runtime support installer docs
git commit -m "fix: describe resulting behavior"
git push -u origin fix/short-description
```
